# Quiz Game (OOP)

A command-line true/false quiz game built in Python using object-oriented
programming.

## Features

- Loads a bank of questions from a data file
- Tracks the score as you answer
- Reports your final score at the end

## Design

Split into classes, each with a single responsibility:

- `Question` - models a single question and its answer
- `QuizBrain` - runs the quiz, checks answers and keeps score

## How to run

Run the game: `python main.py`

(Uses only the Python standard library.)
